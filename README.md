#Lumen – Responsive E-Commerce Shopping Cart Application

 Project Overview

Lumen is a fully responsive E-Commerce Shopping Cart Application developed using HTML, CSS, and JavaScript. The application provides users with a seamless online shopping experience by displaying products dynamically from an API, allowing category-based filtering, real-time product searching, and shopping cart management.

The project focuses on creating an interactive and user-friendly interface while implementing core front-end development concepts such as API integration, DOM manipulation, event handling, and browser local storage.

@Features
 
1. Dynamic Product Listing
Fetches product data from an external API.
Displays products dynamically on the webpage.
Eliminates the need for hardcoded product information.

2. Category-Based Filtering
Allows users to browse products by category.
Improves product discovery and user navigation.

3. Real-Time Product Search
Enables users to search products instantly.
Filters products dynamically as users type.

4. Shopping Cart Functionality
Add products to cart.
Remove products from cart.
Update cart contents dynamically.
Display total selected items.

5. Local Storage Integration
Stores cart data in browser Local Storage.
Preserves cart items even after page refresh or browser restart.

6. Order Placement System
Allows users to place orders directly from the cart.
Clears cart after successful order confirmation.

7. Responsive Design
Mobile-Friendly Layout.
Tablet Compatibility.
Desktop Optimization.
Consistent user experience across all screen sizes.

8. Interactive User Experience
Implemented using JavaScript DOM Manipulation.
Event-driven architecture for user interactions.
Smooth and responsive interface behavior.
