#Project Title: Lumen – Responsive E-Commerce Shopping Cart Application 
Developed a fully responsive E-Commerce website using HTML, CSS, and JavaScript.
• Implemented dynamic product listing using data fetched from an API.
• Built category-based filtering and real-time product search functionality.
• Developed a shopping cart system using Local Storage for persistent data storage.
• Implemented add-to-cart, delete-from-cart, and order placement features.
• Designed a modern and responsive user interface compatible with mobile, tablet, and desktop devices.
• Utilized JavaScript DOM Manipulation and Event Handling to create an interactive user experience.
